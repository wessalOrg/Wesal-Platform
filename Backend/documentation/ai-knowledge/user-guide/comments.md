## العربية

وفق المعلومات الرسمية، يستطيع أي مستخدم مسجل إضافة تعليق، بينما لا يستطيع الزائر التعليق.

ملاحظة تحقق: التنفيذ الحالي يطلب مستخدماً مسجلاً مصادقاً ويمنع أصحاب القاعات من التعليق على أي قاعة؛ لذلك توجد حاجة إلى توحيد القاعدة الرسمية مع التنفيذ.

## English

Official information says any logged-in user can add a comment, while guests cannot.

Verification note: the current implementation requires an authenticated Registered User and prevents Hall Owners from commenting on any hall. The official rule and implementation need alignment.
