## العربية

بحسب القاعدة الرسمية، التقييم متاح فقط للمستخدمين الذين حجزوا القاعة. لا ينبغي اعتبار هذه القاعدة مؤكدة تشغيلياً حتى يتم التحقق من تطبيقها في الخلفية الحالية.

ملاحظة تحقق: التنفيذ الحالي يطلب مستخدماً مسجلاً مصادقاً وليس صاحب قاعة، لكنه لا يتحقق من وجود حجز سابق قبل إنشاء التقييم.

## English

According to the official rule, ratings are available only to users who have booked the hall. This must not be presented as operationally confirmed until the current backend implementation is verified or aligned.

Verification note: the current implementation requires an authenticated Registered User who is not a Hall Owner, but does not verify a prior booking before creating a rating.
