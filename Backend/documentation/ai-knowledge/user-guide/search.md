## العربية

ابحث عن القاعات المعتمدة من صفحة القاعات باستخدام الاسم أو المنطقة أو المنطقة الفرعية أو التاريخ. يمكنك أيضاً سؤال مبروك عن القاعات؛ وعند طلب معلومات متغيرة مثل التوافر، يعتمد مبروك على البيانات المباشرة وليس على معلومات ثابتة. الحجز الحالي يختار تاريخاً وفترة واحدة أو أكثر، وكل فترة حجز تتكوّن من ساعة.

## English

Search approved halls by name, region, area, or date. You can also ask Mabrook to help find halls; for changing information such as availability, Mabrook uses live data rather than static guidance. The current booking flow selects a date and one or more booking slots, each one hour long.
